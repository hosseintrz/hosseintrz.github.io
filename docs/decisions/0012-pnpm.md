# ADR 0012 — Package manager: pnpm

**Status:** Accepted
**Date:** 2026-10-09

## Context

Plan default; fastest install with strict node_modules layout.

## Decision

pnpm, pinned via `packageManager` in package.json. pnpm 12 requires explicit
build-script approval — approved packages live in `pnpm-workspace.yaml`
(`allowBuilds: esbuild, lefthook, sharp`).

## Consequences

- CI uses `pnpm/action-setup@v4` (reads `packageManager`) + `--frozen-lockfile`.
- New deps with postinstall scripts need an `allowBuilds` entry.
